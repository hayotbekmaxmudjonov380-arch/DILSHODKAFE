# 🍽️ Kafe Restoran Dilshod

Xonqadagi eng shinam va zamonaviy milliy hamda yevropa taomlari restorani uchun tayyorlangan premium landing page.

## ✨ Xususiyatlar
- **3D Motion & Tilt:** Kursor harakatiga dinamik moslashuvchi 3D kartochkalar.
- **Dark Luxury Dizayn:** Zamonaviy qorong'u gastronomiya uslubi (Gold, Obsidian, Glassmorphism).
- **Interaktiv Menyu:** Milliy taomlar, Fast-food, Ichimliklar va Desertlar toifalari bo'yicha silliq filtrlash.
- **Onlayn Stol Band Qilish:** Mehmonlar soni, sana va vaqtni tanlash hamda modal tasdiqlash tizimi.
- **Responsive (Moslashuvchan):** Mobil telefonlar, planshetlar va kompyuterlar uchun 100% moslashgan.

## 🚀 Ishga tushirish
Fayllarni brauzerda ochish uchun:
- `index.html` faylini brauzeringizda (Chrome, Edge) oching.
Yoki lokal server orqali:
```bash
python -m http.server 5173
```
So'ng brauzerda `http://localhost:5173` manziliga kiring.

## 📁 Fayllar tuzilishi
- `index.html` — Sahifaning HTML5 semantik strukturasi
- `style.css` — Hashamatli dizayn tizimi, CSS o'zgaruvchilari va animatsiyalar
- `app.js` — 3D inersiya, menyu filtrlash va stol bron qilish logikasi
- `AI_LANDING_PAGE_PROMPT_SPEC.md` — Framer AI, Midjourney v6 va DALL-E 3 uchun tayyor prompterlar to'plami
